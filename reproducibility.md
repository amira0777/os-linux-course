# Повторение диагностики

1. Нажать `Win + R`, ввести `winver` и записать редакцию Windows, версию и сборку.
2. Открыть «Параметры → Система → О системе», записать процессор, RAM и тип системы; скрыть имя устройства и ID перед снимком.
3. Открыть Диспетчер задач (`Ctrl + Shift + Esc`) → «Производительность». По очереди выбрать CPU, Memory, Disk и GPU, записать значения и сделать снимки.
4. В Диспетчере задач открыть «Процессы», оставить видимыми минимум три процесса и столбцы CPU и Memory, затем сделать снимок.
5. Нажать `Win + R`, ввести `msinfo32`, проверить ОС, тип системы, процессор, RAM и BIOS Mode; скрыть личные данные перед снимком.
6. В PowerShell можно выполнить безопасные команды, которые использовались при проверке: `Get-CimInstance Win32_OperatingSystem`, `Get-CimInstance Win32_Processor` и `Get-Volume -DriveLetter C`.
7. Сохранить изображения в `assets/screenshots/` под требуемыми именами и проверить относительные ссылки в Markdown.
