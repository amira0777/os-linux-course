# Исследование ПК

Использованы встроенные средства Windows: `winver`, «Параметры → Система → О системе», Диспетчер задач, `msinfo32` и PowerShell.

| Характеристика | Способ 1 | Способ 2 | Совпало? / комментарий |
|---|---|---|---|
| Версия Windows | `winver`: Windows 11 Home Single Language, 25H2, 26200.9168 | `msinfo32`: Windows 11 Home Single Language, 10.0.26200 Build 26200 | Да: совпадают редакция и базовый номер сборки; `winver` показывает также номер обновления .9168 |
| Модель процессора | «Параметры»: Intel(R) Core(TM) Ultra 7 256V | Диспетчер задач: Intel(R) Core(TM) Ultra 7 256V | Да |
| Объём RAM | «Параметры»: 16,0 ГБ | Диспетчер задач: 16,0 ГБ | Да |

![Сведения о ПК](../../assets/screenshots/02_about.png)
Этот экран подтверждает модель процессора, установленную RAM и 64-битный тип системы.



![Процессор](../../assets/screenshots/03_cpu.png)
Диспетчер задач показывает 8 ядер, 8 логических процессоров и включённую виртуализацию.


![Память](../../assets/screenshots/04_memory.png)
На снимке указано 16,0 ГБ памяти; в момент наблюдения использовалось 13,5 ГБ.



![Процессы](../../assets/screenshots/07_processes.png)
На снимке одновременно работают системные и пользовательские процессы, что показывает многозадачность.


![Сведения о системе](../../assets/screenshots/08_msinfo32.png)
`msinfo32` подтверждает ОС, тип x64, процессор и режим BIOS UEFI.



## Наблюдаемые процессы

| Процесс | Назначение | CPU / RAM в момент снимка |
|---|---|---|
| System | системный процесс Windows | 1,5% / 0,1 МБ |
| Task Manager | просмотр процессов и ресурсов | 1,3% / 125,9 МБ |
| Microsoft Word | работа с документами | 0,6% / 132,2 МБ |

Пользовательское пространство содержит обычные программы, например Microsoft Word и Диспетчер задач. ОС управляет CPU, RAM, диском и устройствами, чтобы программы безопасно делили ресурсы. Посредничество ОС видно в Диспетчере задач: он показывает распределение процессора, памяти, диска и сети между программами.
