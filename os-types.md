# Типы ОС

## Классификация установленной Windows

| Признак | Тип | Почему так считаю | Наблюдение на ПК |
|---|---|---|---|
| Назначение | настольная | ОС предназначена для работы на персональном компьютере | Windows 11 Home установлена на ноутбуке |
| Число задач | многозадачная | одновременно выполняет много программ и служб | в Диспетчере задач видно 402 процесса |
| Пользователи | многопользовательская по возможностям | ОС поддерживает отдельные учётные записи и права | Windows содержит средства управления учётными записями |
| Интерфейс | комбинированный | есть графическая оболочка и командные средства | доступны «Параметры», Диспетчер задач и PowerShell |
| Сфера применения | общего назначения | подходит для учёбы, программирования и обычной работы | на ПК используются VS Code и Python |
| Сеть | сетевая | ОС умеет работать в локальных сетях и интернете | в Диспетчере задач есть столбец «Сеть» |

![Запущенные процессы](../assets/screenshots/07_processes.png)

На снимке одновременно видны System, Task Manager, Microsoft Word и другие процессы. Это подтверждает многозадачность Windows.

## Сравнение ОС

| ОС | Где применяется | Тип по назначению | Многозадачность | Интерфейс | Ключевое отличие |
|---|---|---|---|---|---|
| Windows 11 Home Single Language | персональные компьютеры | настольная, общего назначения | да | графический и командный | широкая поддержка обычных ПК-программ |
| Ubuntu | ПК, учебные и рабочие станции | настольная, общего назначения | да | графический и командный | свободный Linux-дистрибутив |
| Android | смартфоны и планшеты | мобильная | да | графический | ориентирована на сенсорные устройства и мобильные приложения |
| FreeRTOS | микроконтроллеры и встраиваемые устройства | специализированная ОС реального времени | да | обычно без графической оболочки | рассчитана на предсказуемую реакцию на события |

Нельзя считать, что все ОС предназначены для одинаковых задач. Windows и Ubuntu нужны для универсальной работы на компьютере. Android ориентирован на мобильные устройства и сенсорный интерфейс. FreeRTOS применяется во встраиваемых системах, где важна быстрая реакция. Поэтому отличаются интерфейс, набор ресурсов и требования к работе ОС.
